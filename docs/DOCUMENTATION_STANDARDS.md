# Documentation Standards

## Formatting
- Use Markdown for all documentation files.
- Start each document with a clear title and purpose statement.
- Use headings and subheadings to organize content logically.
- Include tables of contents for longer documents.

## Link Integrity
- Use the GitHub anchor generation algorithm for all internal links:
  - Lowercase all letters
  - Replace spaces with hyphens
  - Remove periods and special characters (except hyphens)
  - Convert ampersands to double hyphens
- Validate all links after documentation updates.

## Maintenance
- Update documentation whenever code or architecture changes.
- Ensure all new features and changes are documented.
- Use the TOC-heading synchronization and DRIP methodologies for large-scale updates.

## Accessibility
- Follow WCAG 2.1 AA guidelines for readability and navigation.
- Use descriptive link text and headings.

## Review
- Peer review all documentation changes before merging.
- Use status indicators and priority system for documentation tasks.
